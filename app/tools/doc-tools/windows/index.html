Windows 桌面版

依赖本地 Office / WPS 或 Jupyter；PDF 与图片互转请用网页版。

桌面专用：word2pdf、ppt2pdf、ppt2img、nbopen（拖文件到 exe 或命令行运行）。

Word / PPT 需 Office 或 WPS；nbopen 需本地 Jupyter。

本地打包 
cd noomings/desktop-doc-tools
pip install -r requirements.txt
build_all.bat

产物在 dist\。也可直接 python tools/... 运行，见该目录 README。

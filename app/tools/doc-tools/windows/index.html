Windows 桌面版

依赖本地 Office / WPS 或 Jupyter · PDF 与图片互转请用网页版。

桌面专用：word2pdf、ppt2pdf、ppt2img、nbopen（拖文件到 exe 或命令行运行）。

Word / PPT 需 Office 或 WPS · 编辑 Notebook 需本地 Jupyter。

源码在本站 GitHub 仓库 desktop-doc-tools/（不提供预编译 exe，需自行打包）。

本地打包

克隆 nooming.github.io 后：

cd desktop-doc-tools
pip install -r requirements.txt
build_all.bat

产物在 dist\。也可直接 python tools/... 运行，见 desktop-doc-tools/README.md。

# Markdown 阅读示例

这是 noomings 里的示例文档。打开 `?doc=sample` 会加载它。

## 能做什么

- 粘贴 Markdown
- 打开或拖入本地 `.md`
- 用 `catalog.json` 列出仓库里的文档（GitHub Pages 不能列目录）

## 代码

```js
marked.parse(text);
DOMPurify.sanitize(html);
```

> 渲染只在浏览器里完成，不上传。

| 入口 | 说明 |
| --- | --- |
| 粘贴 | 左侧编辑，右侧预览 |
| 目录 | `?doc=id` |

专题 HTML（开发者工具实战、猫抓笔记）仍是独立页面，以后可以迁进阅读器，现在先不改。

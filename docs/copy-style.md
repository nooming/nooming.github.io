# 全站文案规范

面向用户的中文：**短、可扫读**（信息流式排版），用词**准确、克制**；不用口语梗，也不写说明书腔。

## 语气

- **短句 + 中间点**：并列用 ` · `，少用分号与长从句。
- **专业名词保留**：PSO、Base64、PNG、MBTI、本地 / 外部站点等。
- **人称**：默认省略「你」；不写「拍板」「图一乐」「随开随玩」等口语。
- **外链**：角标 `外链`；描述用「外部站点」。

## 顶栏信息架构（v3）

**首页 · 实验 · 工具 · 阅读 · 娱乐**（网址导航在首页卡片，无「发现」顶栏）

| 顶栏 | 侧栏分组要点 |
|------|----------------|
| 首页 | **独立入口** 三格：导航 · 笔记 · Citywalk（`#discover`）；导航页与首页同壳 |
| 实验 | 物理 · 图像 · 测量（质子 / 像素涌流 / 风扇转速） |
| 工具 | 文档 · 编码与媒体 · 图像（OCR）· 随机 · 展示 |
| 阅读 | `app/read/`：Markdown · 站内长文 |
| 娱乐 | 棋类 · 卡牌 · 街机 · 问卷 · 游戏工具（含抽卡规划） |

`app/` 按顶栏分域：`lab/` · `tools/` · `read/` · `play/`；独立入口三格与实践见 `navigation/`、`notes/`、`citywalk/`、`parking-pso/`。详见 [app-ia.md](./app-ia.md)。

## 固定用语

| 场景 | 写法 |
|------|------|
| 版权行 | `© 2026 noomings · 非商用` |
| 外链角标 | `外链` |
| 返回首页（菜单） | `回首页` |
| GitHub | `GitHub · nooming` |
| 文件类工具（PDF/OCR/音频等） | `文件不发送至服务器` 或 `浏览器端处理 · 文件不发送至服务器` |
| 图像 / OCR 隐私 | `图像仅在浏览器端处理`（不用「图不离开浏览器」） |
| 笔记 / 灯牌等仅存 local | `数据仅存于本机浏览器 · 不同步` |
| 本地演算 / 转码 | `本地演算` / `本地转码`（少用「纯本地」「本机转」） |
| 空状态 / 未找到 | `未找到…` / `请更换…` / `请稍后重试`（不用「试试」「…吧」「啦」） |
| 成功复制 / 导出 | `已复制` / `已下载` / `可直接分享`（不用「去分享吧」） |

## 首页区块

首页 **独立入口**（导航 · 笔记 · Citywalk）+ **实践**（停车、物理外链）。不用「常用」（易误解为按使用频率排序）。

## 避免

- 口语顶栏「玩」、决策单独顶栏（已合并进工具 / 娱乐）
- 顶栏「发现」（导航已回首页）
- 口语隐私梗：`图不离开浏览器`、`文字留在本机`、`文件不上传`（改为上表固定用语）
- 句尾语气词：`吧` `啦`；祈使口语：`试试` `一键`（产品可写「快速生成」）
- 过度软化的失败提示：`好像不太顺畅`、`联系不上`（改为「请稍后重试」「服务暂不可用」）

维护：用户可见文案对照本表；导航以 `assets/js/site-shell.js` 为准。

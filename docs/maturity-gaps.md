# 独立项目成熟度盘点

面向 `app/parking-pso` 与 `app/citywalk` 的产品/工程盘点。✅ 已在本轮落地，⏳ 仍建议补。

## 结论

两个项目都已经从「能跑的演示」进入「可交付的小产品」：核心流程、离线降级、移动端、数据持久化和文案都可用。距离「成熟产品」的主要差距不在页面样式，而在 **可恢复性、可观测性、数据主权、测试与发布流程**。

## parking-pso

| 维度 | 差距 | 状态 |
|------|------|------|
| 编辑容错 | 画错/误删只能重来 | ✅ 撤销 / 重做（最近 40 步，按钮入口） |
| 场景理解 | 用户不知道下一步缺什么 | ✅ 场景体检：道路/入口/楼/车位/优化检查，附操作按钮 |
| 保存信任 | 不知道有没有保存成功 | ✅ 自动保存时间 / 失败提示；本地持久化 + 重载验证 |
| 数据搬迁 | 换设备会丢场景 | ✅ JSON 导出/导入；⏳ 还没有云端方案库的公开分享 |
| 离线 | API 不可用时仿真失败 | ✅ 本地 exact 优化 + 本地估算时间轴 |
| 结果复用 | 指标只在页面里 | ✅ 「复制摘要」+ 方案库/对比报告；⏳ 还没有 PDF/PNG 报告 |
| 新手引导 | 4 步流程但没有说明数据/离线 | ✅ 「使用说明与数据」折叠块 + 场景体检 |
| 存储版本 | localStorage 无 schema 版本 | ✅ `schemaVersion` 写入；旧数据按 1 兼容 |
| 错误兜底 | 单个模块失败可能只打 console | ✅ 全局 error / unhandledrejection 提示，建议先导出 |
| 测试 | 没有自动回归 | ⏳ 建议补 Playwright/CDP 冒烟（加载、优化、撤销、离线仿真） |
| 无障碍 | canvas 仍以指针操作为主 | ⏳ 建议补「用表单编辑」路径或键盘编辑模式 |
| 可安装 | 没有 PWA | ⏳ 静态站可以加 manifest + service worker |

## citywalk

| 维度 | 差距 | 状态 |
|------|------|------|
| 路线决策 | 一次只能看一条路线 | ✅ 「换一种走法」+ 当前/上一版指标对比，可来回切换 |
| 行程落地 | 结果只能看，不能进日历 | ✅ 行程时间轴 + `.ics` 日历导出 |
| 数据主权 | 本地缓存无法导出/清理 | ✅ 「我 → 账号 → 数据与隐私」导出本机 JSON / 清除本机数据 |
| 账号恢复 | 5xx 会清登录态、同步会假成功 | ✅ 只在 401 清 token；同步支持拉取内嵌套推送 + 覆盖前备份 |
| 地图失败 | 空白地图 + 卡在定位中 | ✅ 可重试占位、5 秒定位超时、回退当前城市/天气状态 |
| 移动端 | 出结果强制全屏、站点不能排序 | ✅ 结果半屏；上移/下移；首次进入半屏 |
| 安全 | 分享参数可注入、postMessage 不限来源 | ✅ 城市名白名单字符 + 渲染转义；限制同源消息 |
| 性能 | 社区封面 1.5MB、POI 增强重复请求 | ✅ WebP（约 560KB）、POI 增强缓存 |
| 深色模式 | 品牌为浅色，未做深色 | ⏳ 需单独设计；当前显式 `color-scheme: light` |
| 可观测性 | 前端错误只打 console | ✅ 全局错误兜底提示 + 「我」页云端服务状态；⏳ 建议接错误上报 |
| 测试 | 没有自动回归 | ⏳ 建议补登录/同步/发布/分享链路的 mock 测试 |
| 账号注销 | 只能清本地，云端注销未做 | ⏳ 需要后端删除接口与二次确认 |
| PWA | 没有离线壳 | ⏳ 地图依赖网络，价值有限；可离线保存行程 |
| 可维护性 | `community.js` 仍是单文件大模块 | ⏳ 建议按 feed / buddies / me / auth 拆模块 |

## 建议的下一阶段

1. **parking**：全局错误边界、存储 schema 版本、CDP 冒烟测试、PWA。
2. **citywalk**：云端账号注销、错误上报/诊断面板、社区模块拆分、深色主题（若品牌需要）。
3. 两者都补一个「状态页」：当前是否在线、最近同步/保存时间、缓存占用、清除入口。

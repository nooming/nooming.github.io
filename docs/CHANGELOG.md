## 未发布 · 2026.11

> 首页的独立入口，多了一封写给自己的平行来信。

### 新增

- 首页「独立入口」新增「另一个我」：写下生辰，展开一生的平行来信。
- 首页「另一个我」入口加手写批注：红色印章、手绘箭头与黄色高亮。
- 「另一个我」拆为外部 CSS / JS / 字体 / WebP 资源，首屏 HTML 约 10 KB。
- 金文字形从数字识别脚本中单独拆出，恢复原版金色笔画。
- 烧字转场与故事首屏的构图对齐，消除烧完后的小幅位移。
- 片尾背景左右翻转，并同步手机端裁切。
- 故事正文上翻时，画面遮盖约 36% 扩大阅读空间；默认遮盖，`?read=move` 可看画面上移版本。
- 阅读态改为滚动停稳后进入、回到顶部才退出，并保持正文滚动位置；遮罩为透明渐变。
- 修复「显示全部」隐藏后命盘页重新居中造成的轻微位移。
- 封面印章改为去底透明版本，消除开头与结尾的矩形阴影。
- 修复章节道具的响应式变体丢失透明通道、出现黑色矩形底的问题。
- 命盘页先显示四柱与文字，金文字形最多等 1.5 秒，不再卡住「焚字入卷」。
- 修复手机端出生年份「1996年」被滚轮右侧裁掉的问题。
- 启卷按片尾同款像素粒子反向：约 1.3 万粒、曲线路径与颜色过渡，重排成带扉页标题的相册页，再落到真实生辰页。
- 启卷粒子散开与片尾同节奏，延长到约 4.4 秒，整体约 6 秒。
- 启卷在封面空闲时预计算粒子目标，并让粒子落位、像素页还原与表单淡入交叠，减少阶段切换的停顿。
- 片尾文字改为从上到下逐列显影，去掉飞字和模糊；手机端放大并下移。
- 收紧生辰页底部导航与滚轮字号，恢复书本页面的留白和单行导航。
- 手机端书本改为满屏左侧取景，露出左页边缘，彻底去掉四周边带。
- 启卷粒子像素页按真实相册取景（cover / object-position）生成，与背景对齐。
- 出生页底部导航与页码明显放大：宽屏约 15px / 13px，窄屏自动收档避免换行。
- 移除声音按钮、环境声与音效接口，只保留视觉和触感。
- 字形数据异常时回退到文字字形，并给脚本加版本号，避免旧缓存的错误字形。
- 启卷的取样密度、1.5 秒像素前奏、路径弯曲与颜色过渡参数统一为片尾同款。
- 提高烧字转场画布的分辨率，消除烧开的画面与文字突然变清晰的问题。
- 修正桌面端烧字转场背景只显示上半截、进入故事页后突然换图的问题。
- 修正低高度 PC 片尾「活」被视口裁掉的问题，终章文字按视口高度缩放。
- 启卷时先预取相册扉页底图，消除进入生辰页时背景场景一闪而过的现象。
- 补入同学新增的八字解读文字，并同步更新 WenKai / Brush 字形文件。
- 小字号辅助文字整体放大 1px。
- 移除 `app/another-life/tools` 开发脚本，README 不再引用。
- 移除未引用的 ink-bloom 插画。
- 八字排盘与章节内容在页面内计算，出生信息仅在当前页面内计算。

## v2.5 · 2026.11

> 把站内的按钮、文案和两个独立项目，收进同一套更安静的语言。

### 设计系统

- 新增首帧主题注入与顶栏主题 / 声音开关，偏好保存在本机。
- 主按钮统一为淡黄底、黄边；悬停纯黄，选中态改为淡黄底 + 黄描边。
- 移除站内自定义快捷键与 `kbd` 提示，保留 aria / role / 读屏语义。
- 副标题统一为 ` · ` 短句；按钮改短词，去掉 emoji 与「一键」「无缝」等套话。
- 404、文章页、工具目录补齐统一视觉；工具首页改为可搜索的分组目录。

### 阅读与工具

- 长文页新增自动目录、阅读进度、代码复制和文末上下篇。
- 心理测试双页共用 quiz engine；结果支持复制、分享、重测，刷新直接回到结果。
- Markdown、OCR、像素涌流、灯牌、风扇、质子、文档转换统一深色与语义色。
- 转盘、抛硬币原生重写；删除约 130KB 第三方 min 资源。
- 转盘、抛硬币补转动 / 落地音效；快速选择补抽取反馈。
- 随机决定补预设、历史、复制和本地持久化。
- 文档转换补齐 PDF→图、图片→PDF、PDF→PPTX 与只读 ipynb。

### 棋类

- 五子棋、围棋、象棋拆分引擎 / 棋盘 / 记谱 / AI worker，共用棋类样式。
- 象棋、围棋补与五子棋一致的底部 toast：模式、难度、新局、悔棋、停一手。
- 围棋、星铎棋与牌桌补轻音效；全站声音开关统一控制。

### 独立项目

**停车方案**

- 修正模块顺序，离线也能本地优化与仿真；补触屏缩放、四步工作流和紧凑图例。
- 新增撤销 / 重做、场景体检、方案摘要、自动保存、方案库与对比。
- 界面重构：深色绘图台、玻璃工具条、分段工作台、底部操作 dock、车辆表格和移动端固定操作栏。

**WanderWalk**

- 修复定位覆盖、同步重入、分享注入、5xx 清登录态、地图失败兜底、移动端结果全屏和触屏排序。
- 新增行程时间轴与 `.ics` 导出、「换一种走法」对比、社区本机数据导出 / 清除、服务状态。
- 社区封面转 WebP；补请求超时、POI 缓存和登录防重复提交。

### 维护

- 新增 `.gitattributes` / `.gitignore`；移除日志与无引用样式。
- 修复卡牌按钮构建报错；清理社区、棋类和卡牌死代码。

PRIVACY / 本地优先

隐私说明

更新日期：2026-11-17

noomings.com 是一个个人非商用静态网站。站点没有账号、评论、上传、支付或广告系统，核心工具尽量在浏览器本地运行。

1. 哪些数据只在浏览器本地

以下内容由浏览器处理，本站不会主动上传到服务器：

  • 笔记：绘图、文本和页面数据保存在浏览器存储中，可通过页面内导出功能自行备份。
  • 停车方案：场景、车辆、优化和仿真结果保存在浏览器中，不上传服务器。
  • 另一个我：出生日期、时间、地点和性别只用于当前页面内的本地排盘与叙事计算；页面不会把生辰信息发送到服务器。
  • 摄像头工具：风扇转速页面在获得授权后读取摄像头画面，帧差和频率计算在浏览器内完成；本站不录制、不保存、不上传摄像头画面。
  • 心理测试与抽卡规划：作答、设置和计算结果只用于页面展示或保存在浏览器本地。

2. 浏览器存储

部分工具使用 localStorage 或类似机制保存设置、最近记录和本地方案。它不等同于登录账号，也不会自动同步到其他设备。你可以通过浏览器的“清除网站数据”删除；部分页面也提供导出、清空或重置入口。

3. 服务器日志

网站由腾讯云服务器和 Nginx 提供静态文件。服务器可能按云服务商的安全与运维配置记录访问日志，包括 IP 地址、浏览器 User-Agent、访问时间、请求路径和响应状态。这些日志用于安全防护、故障排查和基础统计，不用于建立个人画像或广告投放。

4. 第三方资源与外链

部分工具会从公共 CDN 加载开源库、字体或 OCR 模型，例如 jsDelivr。浏览器请求这些资源时，CDN 服务商可能收到 IP 地址、User-Agent 等常规请求信息，具体以其隐私政策为准。本站不接入广告、行为分析或跨站跟踪脚本。

站内指向 GitHub、B 站等外部站点的链接，只有在你主动点击后才会跳转；外部站点的数据处理由其自身政策约束。

5. 不收集与不共享

  • 不出售、出租或交换个人信息。
  • 不要求实名注册，不建立用户账号。
  • 不收集支付信息，不提供付费服务。
  • 不主动收集通讯录、精确位置或生物识别模板。

6. 你的选择

  • 拒绝摄像头权限，或在使用后于浏览器设置中撤销权限。
  • 使用浏览器“清除网站数据”删除本地笔记、方案和设置。
  • 不使用需要填写生辰信息的页面；该页面不是网站的必要功能。
  • 通过浏览器无痕模式访问，避免保留本地数据。

7. 未成年人

本站是个人学习与工具站，不面向未成年人提供注册、付费或社交服务。未成年人应在监护人指导下使用，并避免在公共设备上保存私人笔记或生辰信息。

8. 变更与联系

隐私说明更新时会修改本页日期。若对数据处理有疑问，可通过 GitHub Issues 联系。
